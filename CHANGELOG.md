# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.3.5] - 2026-09-11

### Added
- New hold to show keybind for HUD

## [1.3.4] - 2026-08-31

### Added
- Add better crafting compatibility (only for tooltip display)

### Fixed
- Trace crafting and cooking recipe assets separately for greater accuracy

## [1.3.3] - 2026-08-28

### Fixed
- Add guard to avoid tracing nested edit shenanigans

## [1.3.2] - 2026-08-24

### Fixed
- Fix incompat with DaLion.Enchantments

## [1.3.1] - 2026-08-21

### Fixed
- Use NameWithoutLocale consistently.

## [1.3.0] - 2026-08-20

### Added
- Config option to display the first update key
- Config option to display the mod id instead of the mod name
- Config option to show location name on the HUD
- Config option to show event name on the HUD

### Fixed
- Display issue with drawing forged weapon tooltips

## [1.2.0] - 2026-08-15

### Added
- Keybinds to toggle on and off, default unbound.

## [1.1.1] - 2026-08-14

## [1.1.0] - 2026-08-14

- Support for pets in HUD and API

## [1.0.0] - 2026-08-13

### Added
